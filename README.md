# Third Hand

Первый запускаемый вертикальный срез нативного macOS-приложения для управления задачами программирования между несколькими официальными CLI-агентами.

## Что уже работает

- Task-centered SwiftUI interface: sidebar, chat и inspector.
- Создание задачи с названием и выбором Git-репозитория.
- Папка репозиториев по умолчанию в Settings.
- Первое сообщение в чате становится исходным запросом Task.
- Отдельная редактируемая Task Specification: актуальная цель, уточнения пользователя, ограничения, критерии готовности, решения, исключённый scope и открытые вопросы. Обычные ответы в чате не переписывают её автоматически.
- Прикрепление нескольких локальных файлов через кнопку «+» в composer; последние уникальные ссылки сохраняются на уровне Task и доступны следующим попыткам без передачи истории чата.
- Реальный запуск выбранного Codex, Claude Code или Antigravity в отдельной PTY-попытке.
- Потоковый PTY output во время выполнения; raw-текст скрыт настройкой приватности, пока пользователь явно не откроет его.
- Живая индикация работы агента в header, sidebar, чате и над composer: подготовка, анализ, чтение файлов и источников, поиск, команды, изменения, проверки и формирование ответа определяются по фактическим событиям CLI; при отсутствии точного сигнала показывается нейтральное состояние.
- Stop для активного CLI-процесса и блокировка параллельной записи в один репозиторий.
- Реальный Git snapshot: ветка, HEAD, изменённые и untracked файлы, diff stat.
- Live Git-прогресс во время работы: изменённые файлы и строки `+ / −` в inspector.
- Read-only unified diff viewer для tracked и untracked файлов с защитой путей и ограничением размера.
- Локальное сохранение задач.
- Резервная копия `state.json` и безопасная блокировка записи, если состояние повреждено и восстановить его нельзя.
- Удаление задач с подтверждением; репозиторий при этом не удаляется.
- Этапы и вычисляемый прогресс.
- Semantic handoff.
- Checkpoints.
- Маленький machine-readable progress report: после успешной попытки агент может обновить handoff, завершённые этапы и checkpoint, не передавая transcript.
- Реальные build/test recipes для SwiftPM, npm, Gradle и Python: запуск, остановка, live-log, exit code, длительность и Git-fingerprint для определения устаревшего результата.
- Команды проверок и agent CLI разрешаются в абсолютные пути с PATH, подходящим для запуска приложения из Finder.
- Выбор и переключение агента прямо в composer.
- Режим «Авто» с настраиваемым порядком провайдеров и failover только при подтверждённой ошибке лимита.
- Кольца оставшегося лимита: точные окна Codex через официальный read-only app-server и обе группы квот Antigravity через официальную PTY-команду `/usage`. Данные обновляются при активации приложения, после попытки агента, вручную и каждые пять минут в foreground.
- Быстрые кнопки для вариантов ответа и вопросов подтверждения в финальном сообщении агента.
- Capability-driven параметры запуска: модель, усилие, скорость, режим доступа и подтверждения — только там, где официальный CLI их поддерживает.
- Обнаружение Codex CLI, Claude Code и Antigravity (`agy`, с fallback на `antigravity`) в типичных путях.
- Отдельные Settings и macOS commands.
- Системные уведомления о вопросе, готовом ответе, ошибке и завершении задачи; включаются пользователем в Settings и не содержат prompt, diff или terminal logs.

## Граница этой версии

Один send запускает отдельную non-interactive попытку внутри PTY. Быстрые ответы запускают следующую такую попытку. Настоящая интерактивная передача подтверждений в живой PTY и продолжительная TUI-сессия будут добавлены следующим этапом; ошибки авторизации, лимита или разрешений уже возвращаются в чат, а не теряются.

Live output не превращает одноразовый CLI в интерактивную сессию: composer остаётся заблокирован во время попытки, потому что Codex `exec`, Claude `--print` и Antigravity `--print` имеют разные протоколы stdin. Универсальная запись ответов напрямую в PTY была бы небезопасна.

Auto не маскирует произвольные сбои: сеть, авторизация, права и неизвестная ошибка останавливают задачу и требуют внимания. Перед вторым агентом снимается свежий Git snapshot, создаётся checkpoint и обновляется компактный semantic handoff; история чата не передаётся.

Перед каждой попыткой Third Hand заново снимает Git fingerprint. Результат сборки или тестов передаётся агенту как `fresh` только пока репозиторий соответствует снимку проверки; после любого изменения он маркируется `stale`.

Codex возвращается в очередь по официальному времени reset. Antigravity показывает недельное и пятичасовое окна отдельно для Gemini и для Claude/GPT; в sidebar первыми выводятся окна группы выбранной модели, а без явного выбора — безопасный минимум по обеим группам. Для Claude Code, у которого пока нет подключённого официального usage-интерфейса, подтверждённое исполнением исчерпание действует 15 минут; кнопка обновления позволяет снять этот cooldown вручную.

Уведомления доставляются, пока процесс Third Hand запущен. Независимый background Runner, managed worktrees и восстановление активной PTY после полного Quit остаются следующими архитектурными этапами.

## Запуск

В терминале:

~~~bash
./script/build_and_run.sh
~~~

С проверкой, что процесс запустился:

~~~bash
./script/build_and_run.sh --verify
~~~

Готовый bundle создаётся в <code>dist/Third Hand.app</code>.
